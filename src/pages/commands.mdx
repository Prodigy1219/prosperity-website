A cheat sheet for the commands you'll use most often. The full, always-current reference lives on the [wiki's Commands page](https://wiki.prosperitysmp.com/Commands).

<InfoCallout type="info" title="How to read this page">
  - Anything in `<angle brackets>` is a required argument you replace with a real value.
  - Anything in `[square brackets]` is optional.
  - All commands work on both Java and Bedrock unless noted otherwise.
</InfoCallout>

## Quick essentials

The 10 commands you'll use every session:

| Command | What it does |
|---|---|
| `/warp spawn` | Teleport to spawn (the city) — note: plain `/spawn` does **not** work here |
| `/rtp` | Random teleport into the resource world |
| `/sethome <name>` | Set a home you can teleport back to |
| `/home <name>` | Teleport to one of your homes |
| `/bal` | Check your money |
| `/jobs stats` | See your job levels and XP |
| `/shop` | Open the admin shop (fallback prices) |
| `/find <item>` | Find player-run shops selling that item |
| `/contracts` | See active public contracts |
| `/tpa <player>` | Request to teleport to another player |

## Communication

ProsperitySMP supports both **global** and **local** chat.

| Command | What it does |
|---|---|
| `/g <message>` | Send a one-off global message (one-shot) |
| `/l <message>` | Send a one-off local-area message (one-shot) |
| `/g` | Toggle to global chat (sticky) |
| `/l` | Toggle to local chat (sticky) |
| `/msg <player> <message>` | Private message a player |
| `/r <message>` | Reply to last private message |
| `/mail send <player> <message>` | Send mail (they get it when they log in) |
| `/seen <player>` | When was a player last online |
| `/list` | See who's online |

**Voice chat** (Java only): [Simple Voice Chat](https://wiki.prosperitysmp.com/Simple_Voice_Chat) provides proximity audio — see the wiki for setup.

## Jobs

You have **3 job slots**. Each job caps at level 50.

| Command | What it does |
|---|---|
| `/jobs browse` | See all available jobs and what they pay |
| `/jobs join <jobname>` | Join a job (Miner, Farmer, Builder, Woodcutter, Hunter, Fisherman) |
| `/jobs leave <jobname>` | Leave a job (you keep titles but lose the slot) |
| `/jobs stats` | See your current jobs, levels, and XP |
| `/jobs info <jobname>` | See payment rates for a specific job |
| `/jobs top <jobname>` | Top 10 players in that job |

### Job titles

| Command | What it does |
|---|---|
| `/title` | List the titles you've unlocked |
| `/title <jobname>` | Pin that job's title to display |
| `/title auto` | Auto-display your highest-tier title (default) |

### Skill trees

| `/skillnode <node>` | Bedrock-friendly text version |
| `/headlamp` | Toggle the Miner headlamp perk |
| `/treefeller` | Toggle the Woodcutter treefeller perk |

## Shops & trading

- **Admin shop** — fallback fixed-price store. Use `/shop`.
- **Player shops** — chest shops around the market district. Use `/find` to locate them.
- **Auction house** — server-wide item marketplace ([wiki](https://wiki.prosperitysmp.com/Auction_house)).

| Command | What it does |
|---|---|
| `/shop` | Open the admin shop GUI (includes the [Bazaar](https://wiki.prosperitysmp.com/Bazaar) catalog section) |
| `/sellhand` | Sell whatever's in your main hand |
| `/sellall <item>` | Sell all of one item type from your inventory |
| `/find <item>` | Find player shops selling that item (distance-sorted) |
| `/shopname <name>` | Claim a shop name (so players can find you by name) |
| `/market <item>` | Median price from recent real player trades |
| `/ah` | Open the auction house |
| `/trade <player>` | **Currently disabled.** Direct player-to-player trade window, turned off pending a fix to an item-loss bug. Use `/ah` or a chest shop. |

<InfoCallout type="info" title="Bedrock players">
  Bedrock players use **`/buy`** and **`/sell`** as text-based shop commands instead of the `/shop` GUI. Type `/buy` to see what's available.
</InfoCallout>

## Public contracts

The contract board pays players to turn in raw materials ([wiki](https://wiki.prosperitysmp.com/Contracts)).

| Command | What it does |
|---|---|
| `/contracts` | List active contracts |
| `/contractinfo <id>` | Full details for one contract (cooldown, daily count) |
| `/deliver <id>` | Turn in your inventory items for that contract |

## Real estate

Renting and buying happen through the **plot signs** — right-click a sign to see the price and confirm ([wiki](https://wiki.prosperitysmp.com/Plot_rental)). Commercial plot purchases are paused until the new map; rentals are open.

| Command | What it does |
|---|---|
| `/arm gui` | Your plots and rentals in one menu |
| `/arm info` | Region info for the plot you're standing on |
| `/arm listregions` | List every region you own or rent |
| `/arm limit` | How many plots/rentals you can hold |
| `/arm addmember <region> <player>` | Let a friend build on your plot (they must be online) |
| `/arm removemember <region> <player>` | Revoke that access |

## Crates, prestige & advanced tools

| Command | What it does |
|---|---|
| Right-click a crate item | Open it — no key needed ([wiki](https://wiki.prosperitysmp.com/Crates)) |
| `/prestige` | The prestige menu — reset a L50 job for permanent bonuses ([wiki](https://wiki.prosperitysmp.com/Prestige)) |
| `/smithy` | The Master Smith — Efficiency/Fortune beyond vanilla ([wiki](https://wiki.prosperitysmp.com/Master_Smith)) |
| `/buydrill <1-3>` | Buy a mining drill — tiers gate at Miner L15/L30/L45 |
| `/buyharvester <1-3>` | Buy a farming harvester — same gates on Farmer |

Prestige tiers: Reborn → Twice-Forged → Thrice-Forged → Mythic → Eternal.
